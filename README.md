# Moms on Teaching USA Website

A responsive educational website developed for **Moms on Teaching USA**, an online one-on-one tutoring platform connecting students with qualified Teacher-Moms.

The website was designed to provide parents with a clean, modern experience while showcasing tutoring programs, pricing, curriculum information, locations, and contact details.

---

## Project Overview

This website was built to establish Moms on Teaching USA's online presence and communicate its tutoring services through a premium, user-friendly interface.

The design focuses on:

- Modern educational branding
- Responsive layouts for desktop, tablet and mobile
- Fast loading static pages
- Clean typography
- Premium UI inspired by modern SaaS websites
- Accessible navigation
